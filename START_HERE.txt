CARE FLOW AI — START HERE (Windows)
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Copy .env.example to a new file named .env
6. Add your Gemini API key to .env (do not send the key to anyone).
7. Run: npm run dev
8. Open the Local URL shown in the terminal (usually http://localhost:5173).

If no page opens, check that the terminal still shows both the Vite URL and
"CareFlow AI API server running at http://localhost:3001".
Do not upload or share your .env file.
